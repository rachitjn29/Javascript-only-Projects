# 🌦️ Weather App

A modern and responsive **Weather App** built using **HTML, CSS, and JavaScript**. It fetches real-time weather data from a weather API and displays current weather conditions with a clean and user-friendly interface.

## 🚀 Features

- 🌍 Search Weather by City Name
- 🌡️ Real-Time Temperature
- ☁️ Weather Condition
- 💧 Humidity
- 🌬️ Wind Speed
- 👁️ Visibility
- 🌅 Sunrise & Sunset Time
- 📍 Country Information
- ❌ Invalid City Error Handling
- ⏳ Loading State
- 📱 Fully Responsive Design
- 🎨 Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Weather API
