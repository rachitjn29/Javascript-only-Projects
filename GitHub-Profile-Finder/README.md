# 👤 GitHub Profile Finder

A modern and responsive GitHub Profile Finder built using **HTML, CSS, and JavaScript**. Search any GitHub username to instantly view profile details, statistics, and a direct link to the user's GitHub profile.

## 🚀 Features

- 🔍 Search GitHub Users
- 👤 Display Profile Picture
- 📝 Name, Username & Bio
- 📍 Location
- 🏢 Company
- 👥 Followers & Following Count
- 📂 Public Repositories Count
- 🔗 Direct GitHub Profile Link
- 📱 Fully Responsive Design
- 🎨 Clean Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub REST API
