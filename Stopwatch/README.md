# ⏱️ Stopwatch

A clean and responsive Stopwatch built using **HTML**, **CSS**, and **JavaScript**. It includes start, pause, reset, and lap recording functionality with a modern glassmorphism UI.

## 🚀 Features

- ▶️ Start
- ⏸️ Pause
- 🔄 Reset
- 🏁 Record Laps
- 🗑️ Clear All Laps
- 📱 Responsive Design
- 🌙 Modern Glassmorphism UI
- ⚡ Real-time Stopwatch

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
