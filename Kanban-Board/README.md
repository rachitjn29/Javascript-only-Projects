# 📋 Kanban Board

A modern and responsive **Kanban Board** built using **HTML, CSS, and JavaScript**. It helps users organize tasks efficiently with drag & drop functionality, task editing, and local storage support.

## 🚀 Features

- ➕ Add New Tasks
- ✏️ Edit Existing Tasks
- 🗑️ Delete Tasks
- 🖱️ Drag & Drop Between Columns
- 💾 Local Storage Support
- 🔄 Automatic Data Persistence
- 📂 Organize Tasks by Status
- 📱 Fully Responsive Design
- 🎨 Modern UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
