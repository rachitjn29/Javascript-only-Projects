# 🧠 JavaScript Quiz App

A modern and interactive Quiz Application built using **HTML, CSS, and Vanilla JavaScript**. This project tests users with multiple-choice questions, provides instant feedback, tracks progress with a countdown timer, and displays the final score with performance analysis.

## ✨ Features

- 🎯 10 Multiple Choice Questions
- ⏳ 15-Second Countdown Timer
- 📊 Animated Progress Timeline
- ✅ Instant Answer Validation
- ❌ Incorrect Answer Highlighting
- 💡 Automatically Shows Correct Answer
- 🚫 Options Disabled After Selection
- ⏭️ Auto Next Question (2 Seconds)
- 📍 Live Question Counter
- 📈 Score & Accuracy Percentage
- 🏆 Performance Message
- 🔄 Restart Quiz
- 🚪 Quit Quiz
- 📱 Fully Responsive Design
- ⚡ Built with Pure JavaScript (No Frameworks)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)


## 🚀 How It Works

1. Click **Start Quiz**.
2. Read the question and select an answer.
3. The selected answer is validated instantly.
4. If the answer is incorrect, the correct answer is highlighted.
5. If the timer reaches **0**:
   - "Time Over!" message is displayed.
   - Correct answer is highlighted automatically.
   - The next question loads after 2 seconds.
6. After the final question, the app displays:
   - Final Score
   - Accuracy Percentage
   - Performance Message
