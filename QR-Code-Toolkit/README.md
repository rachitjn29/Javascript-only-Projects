# 🔳 QR Toolkit

A modern **QR Code Generator & Scanner** built with **HTML, CSS, and JavaScript**. Generate custom QR codes, scan QR codes using your camera or image upload, and manage results with a clean, responsive interface.

## ✨ Features

### 🔳 QR Code Generator

* Generate QR codes from text or URLs
* Custom QR size selection
* Custom QR color
* Download generated QR as PNG
* Clear generated QR

### 📷 QR Code Scanner

* Scan using device camera
* Scan QR from uploaded image
* Display decoded result
* Copy scanned text
* Open scanned URL directly
* Start / Stop camera

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

### Libraries

* QRCode.js
* html5-qrcode
