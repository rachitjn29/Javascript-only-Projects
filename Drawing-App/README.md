# 🎨 SketchPad Pro

A modern browser-based drawing application built with **HTML, CSS, and JavaScript** using the **HTML5 Canvas API**. Create freehand drawings, draw geometric shapes, undo/redo changes, and export your artwork as a PNG image.

---

## ✨ Features

- ✏️ Pencil Tool
- 🧽 Eraser Tool
- 📏 Line Tool
- ▭ Rectangle Tool
- ◯ Circle Tool
- △ Triangle Tool
- 🎨 Color Picker
- 📏 Adjustable Size
- ↶ Undo Drawing
- ↷ Redo Drawing
- 🗑️ Clear Canvas
- ⬇️ Download Drawing as PNG
- 📱 Responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- HTML5 Canvas API

## 🚀 How It Works

1. Select a drawing tool.
2. Choose a color.
3. Adjust the brush size.
4. Draw on the canvas.
5. Undo or redo changes if needed.
6. Clear the canvas anytime.
7. Download your artwork as a PNG image.
